# U-DSH Portable v0.1.3

这是 v0.1.2 的启动修复版。**v0.1.2 有已知启动缺陷，请直接使用本版。**

- 修复：本机已装全局 `@deepseek-ai/dsh@0.1.0-rc.7` 时，复用成功、DSH 服务也已经起来，
  但记录激活版本这一步只在便携目录里找内核，抛 ENOENT，被当成启动失败弹框。
  受影响的恰好是 v0.1.1/v0.1.2「复用已有运行时」本该生效的机器。
- `activate()` 在便携目录没有内核时回落到系统发现（仅限频道钉住的版本）；
  `listInstalled` / `status` 的严格语义不变，复用来的内核不会被谎报成已安装。
- 钱包、虾盘云 Provider、U 盘数据边界与 v0.1.2 一致。

## 已验证

- 41 项自动化测试通过，其中包含这次缺陷的回归用例（撤掉修复即以原 ENOENT 失败）。
- ActionParity AP-2：16/16 GUI/CLI 绑定运行时验证通过。
- ShadowFork 上游契约通过。
- 发布包冷启动冒烟（空白本机缓存目录）通过，真实拉起官方 DSH Web UI。
