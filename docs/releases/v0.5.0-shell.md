# U-DSH 壳子版（Windows）v0.5.0 — Electron 窗口版，双击即用

这是 PC 上更"像个产品"的形态：不是开浏览器，而是一个带图标的 Windows 应用窗口。

## 和 WebUI 版的区别

| | 壳子版（本包） | WebUI 版 |
|---|---|---|
| 打开方式 | 双击 `U-DSH.exe`，独立窗口 | 双击 bat，弹浏览器标签页 |
| 观感 | 应用（任务栏图标、窗口） | 网页 |
| 平台 | **仅 Windows**（`dist:mac` 在仓库里被 guard 掉了：mac 壳子需 Apple 公证 $99/年） | Windows + macOS |
| 引擎 | 装 `%LOCALAPPDATA%\U-DSH`（同一套） | 同左 |
| 数据 | 随包 `data/`（同一套） | 同左 |

## 这次修掉的 4 个阻点（壳子版一直没产物的原因）

1. `scripts/test-windows-hidden-console.mjs` 还 import 早已删除的 `resolveWindowsNodeExecutable` → CI 第一步就挂
2. `release.yml` 缺 `prepare:vendor`（vendor 不入库）→ `vendor:check` 必失败
3. 就绪 URL 正则会吃掉 `?token=` → **壳子窗口加载无 token 地址，必然 401**（真产品 bug，不只是测试）
4. smoke 直接 fetch ready URL、且 `kernel.activate(target.version)` 传了 undefined
