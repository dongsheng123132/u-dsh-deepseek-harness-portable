# U-DSH Portable v0.3.2 — 说准、护住数据

这一版没有新功能，只有两件事：**把话说准**、**把用户数据的后路铺好**。
起因是一次外部评审（4 个模型 + 裁判）判定 v0.3.1 的卖点里有过度承诺，我们照单改了。

## 一、卖点修正（评审 FIX-FIRST 第 2 项）

| 之前怎么说 | 现在怎么说 | 为什么 |
|---|---|---|
| 不伤 U 盘 | **引擎不从 U 盘运行，U 盘只写少量数据**（实测：运行中盘上 17 个打开的文件全在 `data/dsh-home`；空转 90 秒写入 **224 KB**） | 严格说不是零写入，exFAT 也没有 journaling，绝对化表述站不住 |
| 原版不改动 | **DSH 核心代码与依赖按固定版本原样打包，外层是 U-DSH 的启动器/安装器** | 包里确实有自研组件，说"整包原版"会误导 |
| 开箱即有额度 | **Electron 桌面版有设备钱包；WebUI 便携版目前需自备 Key** | 评审发现的真问题：两种包能力不同，之前的 README 把两者混在一起说 |
| 数据随盘无缝 | **配置/会话/凭据在盘上，可带到兼容电脑继续用；建议备份、别多机同时用** | "无缝"忽略了盘损坏与并发写入 |

README 中英双版、发布说明都已按这张表改写。

## 二、数据后路（评审 FIX-FIRST 第 1、3 项）

- **新增备份脚本** `scripts/backup-dsh-home.mjs`：一条命令把 `data/dsh-home` 打成带时间戳的 zip，
  默认留最近 5 份；`--to` 可备份到本机/网盘目录（**同盘备份防不了盘损**，脚本会提醒）。
- **多机并用告警**：启动时在 `data/dsh-home/.udsh-instance.lock` 写主机名+pid；若 12 小时内被
  **另一台电脑**用过，启动器明确警告"同时用会导致会话/配置互相覆盖"。
- **首装说明更清楚**：首次在某台电脑启动时，终端先说清"要装约 450–500 MB 到本机，通常 10–60 秒，
  数据仍在 U 盘"，再开始装。

## 三、评审提到但我们没做的（列清楚，不装作做了）

| 评审意见 | 状态 | 原因 |
|---|---|---|
| 会话/配置的原子写 + fsync + 崩溃恢复 | **不做（上游问题）** | 写盘是 DSH 内核自己的行为，改它就和"DSH 核心不改"矛盾。已提供备份脚本兜底；建议提给上游 |
| 代码签名 / macOS 公证 | **未做，属发版前必须解决项** | 没有签名，Windows SmartScreen 和 macOS Gatekeeper 会在首次启动拦截，直接影响首装成功率。面向普通用户放量前必须做 |
| 凭据加密 / Key 不随盘 | **待定，需要产品取舍** | 钱包 Key 明文随盘 = 盘丢即余额风险。两条路：加密存 Key，或 Key 只留本机（换电脑重领）。需要你拍板 |
| 「不伤盘」要有写入量预算与长会话实测 | **部分做**：给了空转 90 秒 224 KB、运行期打开文件的实测；长会话（2 小时）写入量待补 | 需要真实对话才能测 |
| 写入日志轮转 / 只读缓存落本机 | **待评估** | 同上，属于 DSH 内核行为 |
