# U-DSH Portable v0.2.1

这是一次首用体验收束版：不再把“内核状态、检查更新、问题反馈、钱包迁移”等维护功能堆在新用户的第一屏。

## 一键开始使用

- 首屏只保留 **一键开通并充值**：自动申领或恢复虾盘云设备钱包、写入 DSH 配置，再打开系统浏览器的充值页。
- 不创建账号，不需要复制 API Key 到 DSH；充值完成后回到 U-DSH 即可对话。
- 不会自动扣费。支付仍只在系统浏览器的充值页完成。

## 仍然可控

- 复制 Key、换 Key、填入已有 Key、移除本机钱包，全部保留在“管理钱包、备份或换机”里。
- 内核检查和问题反馈继续从 CLI / 系统托盘提供，避免干扰首用路径。
- 设备钱包仍遵守两阶段换 Key、只读验证、离线不阻断 DSH 和本机钱包文件可携带等约束。

## 兼容性

U 盘仍必须使用 **NTFS**。DSH 运行时需要在数据目录创建 junction；exFAT/FAT32 不支持。启动前会探测并给出可执行说明，不会再把裸 `EISDIR` 直接抛给用户。
