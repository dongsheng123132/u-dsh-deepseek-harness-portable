# U-DSH Portable v0.4.6 — 修「充值后余额不刷新」

## 现象

3116 真机充值后，面板余额还是显示老的 / 直接报错。查接口发现：

```
/api/status?balance=1  →  "balance": {"error": "HTTP 429"}
```

**根因：余额接口被服务端限流（429）。** 客户端没做缓存和退避，把 429 当成"余额为空"显示出来，
用户看起来就是"充了钱没到账"。

## 修法（客户端三层）

| 层 | 做法 |
|---|---|
| 缓存 | 余额 30 秒内复用缓存，不再每次都打服务端 |
| 退避 | 撞到 429 后 30 秒内不打服务端，直接回上次已知余额（标 `stale`） |
| 展示 | 面板显示「缓存值（x 秒前）」或「余额暂时查不到：查询太频繁…稍后自动重试」，**永不把错误当余额** |
| 频率 | 左下角按钮轮询 60s → 120s；面板「刷新余额」按钮走 `force=1` 强制刷新 |

实测（Mac 本地）：

```
第 1 次查询 → available=1              （打服务端）
第 2 次查询 → available=1, cached=true, ageMs=1935   （命中缓存，不打服务端）
```
