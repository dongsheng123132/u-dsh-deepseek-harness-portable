# U-DSH Portable v0.4.2 — 按真人体验修的三处

用户在真机上走了一遍，提了三个问题，这版全改：

## 1. 不再"直接弹充值页"

之前新钱包余额≈0 时会自动打开充值页 —— 客户一脸懵："我不是刚打开吗，怎么让我付钱？"

现在：**不弹**。启动时在终端打印清楚的三行提示 + 一个**可点链接**：

```
[U-DSH] 设备钱包：wal_xxxx　密钥 sk-xxxx…
[U-DSH] 余额：¥0.00（1 tokens）
[U-DSH]  钱包还没充值。要充值：双击 U 盘里的「充值」
[U-DSH]  看余额 / 换 Key：双击「钱包」；充完回到 DSH 里直接对话
[U-DSH 钱包] 面板地址：http://127.0.0.1:54050/ （余额 / 充值 / 换 Key，点开即用）
```

钱包面板现在**随启动器一起起来**（不占额外窗口），点链接就在浏览器打开。
想恢复"自动弹充值页"，设 `UDSH_AUTO_RECHARGE=1`。

## 2. 默认模型改成 DeepSeek Flash（之前是 MiniMax，慢）

之前 `models[0]` 直接用服务端返回的第一个模型 —— 实测是 `MiniMax-M3`，又慢又不是客户想要的。

现在按优先级挑：`deepseek-v4-flash` → `deepseek-flash` → `deepseek-chat` → `deepseek-v4-pro`
→ `deepseek-reasoner` → 任一 deepseek → 任一非视频/非 embedding 模型。
实测写入结果：`agent-default-model: { provider: xiapan-cloud, model: deepseek-v4-flash }`。
想固定别的模型：`UDSH_DEFAULT_MODEL=<模型 id>`。

## 3. 余额按「元」显示 + 面板加三步引导

- 终端从 `1 tokens` 改成 `¥0.00（1 tokens）`（1 元 = 50 万 token）
- 面板顶部加一行「三步开聊：① 一键充值 → ② 付款后点刷新余额 → ③ 回 DSH 对话」

## 下一步（等你点头）
