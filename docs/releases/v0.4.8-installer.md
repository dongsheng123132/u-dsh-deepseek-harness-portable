# U-DSH 壳子版 · 安装器形态（v0.4.7 安装包）

## 为什么做安装器

真 U 盘（NTFS F:）实测绿色版：**28,950 个文件 / 891 MB，解压 20 分钟**，启动还把机器拖到失联 —— 客户体验是灾难。

官方 DSH 是"安装版"：一个 Setup.exe，装到本机，桌面图标启动。我们也做成这个形态。

## 形态对比

| | 绿色便携版（旧） | **安装器版（本包）** | WebUI 版 |
|---|---|---|---|
| U 盘上放什么 | 2.9 万个文件 / 891MB | **一个 Setup.exe** | 20 个文件 / 234MB |
| 客户第一步 | 解压 20 分钟 | 双击安装 ~1 分钟 | 解压 1 分钟 |
| 引擎位置 | `%LOCALAPPDATA%\U-DSH` | 同左（装到本机） | 同左 |
| 启动 | U 盘上跑 exe（慢/伤盘） | 本机 + 桌面图标 | 浏览器 |
| 换机 | 插盘即用 | 插盘再装一次 | 插盘即用 |

## 装完什么样

- 开始菜单 + 桌面图标「U-DSH Portable」
- 双击 → 窗口打开 DSH 界面（不是浏览器标签页）
- 左下角「¥ 虾盘云」→ 点开原生钱包窗口（充值 / 复制密钥 / 换一把）
- 数据目录默认随盘：`<安装包同目录>/data`（可在窗口里改）
