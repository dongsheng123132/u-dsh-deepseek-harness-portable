# U-DSH Portable v0.1.0

首个公开测试版：把官方 DeepSeek Harness 做成可从 Windows U 盘直接启动的便携桌面应用。

## 使用方法

1. 下载 `U-DSH-DeepSeek-Harness-Portable-0.1.0-Windows-x64.zip`。
2. 把 ZIP 完整解压到 U 盘目录，不要直接在压缩包里运行。
3. 双击 `U-DSH Portable.exe`。
4. 第一次在一台新电脑运行需要联网准备本机 Node/DSH 内核，可能需要几分钟；以后直接复用。

Windows 当前没有商业代码签名。如果 SmartScreen 拦截，请确认下载地址属于本仓库，再选择“更多信息 → 仍要运行”。

SHA-256：`CB05D27587756B065D062159E1D8806226A2F41EC6EA9F1E58FAD445103A2868`

## 便携数据边界

- U 盘：DSH 配置、会话、Skills、工作状态和虾盘云设备钱包。
- 本机 `%LOCALAPPDATA%\U-DSH`：Node、版本化 DSH 内核、npm/Electron 缓存和日志。

换电脑时用户数据随 U 盘移动；新电脑只需重新准备一次本机运行缓存。

## 本版能力

- 官方 DSH `0.1.0-rc.7` 瘦内核，不修改 DSH Web UI。
- Node `24.19.0` 下载包 SHA-256 校验。
- DSH 临时安装、官方包完整性、版本、入口和必需 peer 依赖校验。
- 国内镜像加速、官方 registry 回退、超时、原子激活和旧内核回退。
- 虾盘云免登录设备钱包：余额、充值、复制 Key、填入已有 Key、两阶段换 Key和本机钱包移除。
- 虾盘云为新用户默认通道，但不锁定提供商；仍可使用 DeepSeek 官方 API 或其他 OpenAI 兼容服务，已有默认提供商不会被覆盖。
- `U-DSH-CLI.cmd` 机器接口，GUI/CLI 共用 ActionParity 动作核心。
- ShadowFork 上游跟随 profile 和下游派生契约。
