# U-DSH v0.4.7 — 壳子版钱包接通 + 余额限流修好

## 一、壳子版（Electron）也能点开钱包了

以前壳子版左下角「¥ 虾盘云」点了没反应：插件只会打开 `127.0.0.1:43110`，而壳子版不跑本地面板。

现在按载体自动分流：

```
WebUI 版：探测 43110 面板 → 有 → 打开网页面板
壳子版：探测不到 → window.open('udsh://wallet')
        → 主进程 setWindowOpenHandler 拦截 → showWalletWindow() 原生钱包窗口
```

## 二、余额不刷新（HTTP 429）

充值后余额显示不对，根因是余额接口被限流 429，客户端把错误当余额：

- 30 秒缓存 + 撞 429 后退避 30 秒
- 失败回落「上次已知余额 + 缓存时间」，绝不把错误当余额显示
- 左下角按钮轮询 60s → 120s

## 三、顺手修的真 bug

`extractReadyUrl` 的正则把 `?token=` 吃掉了 —— 壳子窗口加载的是无 token 地址，**必然 401 打不开**。已修 + 回归测试。
