# U-DSH v0.4.8 — 钱包跟着「U 盘」走（而不是跟着目录）

## 修的那个要命的问题

客户真实反馈：「充值了，余额没变」。查下来不是刷新问题——**钱包跟着"目录"走**：

```
一台机器上攒出 4 个钱包
wal_9c2131f7…  余额 1        D:\u-dsh-test2（0.4.2 测试目录）
wal_68174e…  余额 488,047  ← 客户充的 ¥1 在这里
wal_f393f3c1…  余额 1        F:\U-DSH-Test（绿色版测试）
wal_24ce77cb…  余额 1        C:\…\Programs\U-DSH Portable（今天新装的）
```

客户在新装的版本里当然看不到钱——它自己又领了一个新钱包。

## 新规则：钱包锚定「盘」，不锚定「目录」

解析顺序（命中即**沿用**，日志写明来源；全没命中才新建，且写进统一锚点）：

```
env UDSH_WALLET_FILE
 → <数据目录>/u-dsh-state/device-wallet.json      （老布局兼容）
 → <盘>/.xiapan/device-wallet.json                ← 新建就写这里（跨产品共享）
 → <盘>/.u-dsh/ 、<盘>/data/… 、<盘>/u-dsh/data/…
 → 同盘浅扫一层：<盘>/任意目录/data/u-dsh-state/…
 → 外接盘扫描（Windows D:–Z: / macOS /Volumes/*）
 → 宿主指针 %LOCALAPPDATA%\U-DSH\last-wallet.txt
```

关键点：**装在本机的版本也会扫可移动盘**——客户插回自己那支 U 盘，自动用回盘上的钱包。
