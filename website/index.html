三步开始使用

全程不需要命令行，不需要安装任何运行环境。

  1. 下载压缩包到 Releases 页下载 U-DSH-DeepSeek-Harness-Portable-*-Windows-x64.zip。
  2. 解压到本地硬盘或 U 盘（U 盘须为 NTFS 格式）。首次解压因文件数量多会稍慢，之后启动是秒级。
  3. 双击 U-DSH Portable.exe，等界面出来即可开始对话。首次联网启动自动配好设备 Key。

常见问题

更多内容见 GitHub README。

U 盘为什么必须是 NTFS 格式？exFAT 行不行？

不行。DSH 每次启动要在数据目录下创建目录链接（junction），exFAT/FAT32 不支持，会直接失败。U-DSH 启动前会自动探测并提示改用 NTFS。格式化前请先备份资料。

为什么第一次解压这么慢？

包内是 DSH 的完整依赖闭包，几万个小文件，瓶颈是文件数量而非体积，慢盘上十几分钟属正常。解压一次之后每次启动都是秒级。

可以不用内置额度，换成自己的 API Key 吗？

可以。钱包页提供「填入已有 Key」，支持 DeepSeek 官方 API 或其他 OpenAI 兼容服务，且随时可以换回。

它会给我的电脑留下痕迹吗？

不写注册表、不改环境变量。会话、配置、凭据、工作区全部保存在程序所在目录，删除文件夹即完全卸载。

这是 DeepSeek 官方产品吗？

不是。U-DSH 是社区独立发行版，与 DeepSeek 官方无隶属关系；客户端代码以 MIT 许可开源。
